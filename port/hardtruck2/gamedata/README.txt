Copy your own Hard Truck 2: King of the Road into this folder: everything
from the install directory (for GOG, C:\GOG Games\Hard Truck 2 or the
HardTruck2 folder of a Wine prefix), so that king.exe is right here, next to
COMMON, ENV, MENV, MTB, MTR, MUSIC, TRUCK.INI and the rest.

Only the GOG build (king.exe, 2,908,160 bytes,
sha256 4412a5f6...edd86) is supported: the port is that exe recompiled.

The *.avi intros, unins000.*, goggame-*, dxcfg.exe, ddraw.dll and king.chm
are not needed.

The game writes its settings, saves, warn.log and aimsg.log here.
